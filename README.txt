CAREERPATHRAIPUR — STATIC HTML WEBSITE
======================================

CONTENTS
- index.html          Home
- about.html          About CareerPathRaipur
- services.html       Recruitment services
- job-seekers.html    Candidate information
- employers.html      Employer information
- contact.html        Contact details
- assets/css/style.css  Shared responsive styling

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the navigation menu to open the other pages.

EDITING
- Edit page text in each .html file using a text editor such as VS Code or Notepad++.
- Change colours, spacing and typography in assets/css/style.css.
- Email links currently use careerpathraipur@gmail.com.
- No database, backend, build tools or external JavaScript libraries are required.

PUBLISHING
This is a static website. It can be hosted on any static web host. For a free option, you can use GitHub Pages or another provider's free static hosting tier. Hosting account setup and provider terms may change; check the provider's current terms before publishing.
If you later use cPanel hosting, upload the contents of this folder into the site's public_html directory.

IMPORTANT
- Replace or confirm business details before publication.
- No actual job vacancies, client logos, testimonials, phone number or placement statistics have been invented.
- The website does not collect or store candidate information. Email buttons open an email composer.
- The website makes no guarantee of an interview or employment.
